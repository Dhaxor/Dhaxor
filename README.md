# Hi, I'm Dhaxor 👋

Software engineer working at the intersection of **AI and developer tooling** — I build open-source libraries and tools around **LLM safety, security automation, and context engineering for AI agents**.

## 🤖 AI focus

Most of my current open-source work is about making LLM applications safer and smarter:

- **[injectbench](https://github.com/Dhaxor/injectbench)** — prompt-injection regression testing for LLM apps: a curated attack corpus plus deterministic graders, zero-dependency and drops straight into CI
- **[llm-cloak](https://github.com/Dhaxor/llm-cloak)** — a context firewall for LLM apps: redacts secrets and PII before text reaches a model, restores originals on the way back, and strips injection payloads
- **[open-context-engine](https://github.com/Dhaxor/open-context-engine)** — an open toolkit for building context-aware AI agents: AST-level code understanding (tree-sitter), retrieval, and incident workflows across a VS Code extension, TUI and studio
- **[security-agents](https://github.com/Dhaxor/security-agents)** — local-first Solidity security analysis: Slither findings ingested, exploit hypotheses generated and validated without sending code to a cloud model
- **[ai-skills-library](https://github.com/Dhaxor/ai-skills-library)** — a curated library of AI skills, prompts, workflows and automation patterns

## 🛠️ Open source libraries

- **[super-utils-plus](https://github.com/Dhaxor/super-utils-plus)** — zero-dependency TypeScript utility library in the spirit of Lodash: 140+ fully-typed functions ([npm](https://www.npmjs.com/package/super-utils-plus))
- **[yt-caption-kit](https://github.com/Dhaxor/yt-caption-kit)** — fetch, translate and format YouTube captions and transcripts: typed API, CLI, SRT/WebVTT output ([npm](https://www.npmjs.com/package/yt-caption-kit))
- **[better-mitt](https://github.com/Dhaxor/better-mitt)** — tiny fully-typed EventEmitter for browser and Node ([npm](https://www.npmjs.com/package/better-mitt))
- **[lotame-sdk](https://github.com/Dhaxor/lotame-sdk)** — TypeScript SDK for Lotame Lightning Tag with browser and SSR helpers ([npm](https://www.npmjs.com/package/lotame-sdk))
- **[mynota](https://github.com/Dhaxor/mynota)** — minimal browser text editor where the whole note lives deflate-compressed in the URL — shareable, no backend
